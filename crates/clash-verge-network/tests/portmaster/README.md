# Pinned Portmaster protocol corpus

`rust_info_test.bin` is copied unmodified from Safing Portmaster at commit `21a2b0647fe98bd67cd2738853c29f736eb888a7`, path `windows_kext/kextinterface/testdata/rust_info_test.bin`. It is GPL-3.0, as is the containing project; see the adjacent LICENSE. The fixture is generated by the donor's `windows_kext/protocol/src/info.rs` tests, and is intentionally prefixed with one malformed IPv4 frame followed by 1,000 serialized events covering all seven event types.

Source: https://github.com/safing/portmaster/tree/21a2b0647fe98bd67cd2738853c29f736eb888a7/windows_kext

The compatible bounded decoder is based on `protocol/src/info.rs`, `kextinterface/info.go` and the explicit command/verdict values in `kextinterface/command.go`. Wire fields, integer byte order and event semantics are retained; unsafe typed pointer casts are not reused. Packet payloads are consumed without retaining them in the monitor event. Bandwidth values are native interval deltas, not mihomo cumulative snapshots. End events carry process/tuple but no native request ID, so they cannot prove unique flow correlation by themselves.

This fixture proves binary compatibility only. It does not certify the driver, device ACLs, process identity, loading, fail behavior or per-app routing. No donor driver or service executable is included.
